# Public and private material

Publish: reference source, tests, synthetic fixtures, limitations, public policy links, API contracts, evaluation definitions and the independent collaboration proposal with https://a2zsoc.com.

Keep private: credentials, raw consent receipts, identity records, client data, incident reports, negotiation strategy, margins, customer-specific pricing, unpublished contracts and identifiable pilot evidence. Forum discussion does not authorize uploading a deck to a CNCF channel or contacting administrators.

Community participation never implies marketplace registration. Catalog publication and commercial contact need separate opt-in. A2Z SOC must disclose its role if it also supplies services, and must distinguish paid placement from independent recommendations.
